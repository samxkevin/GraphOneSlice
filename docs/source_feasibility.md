## Notes

- `usable` means the endpoint was accessible, parsed, and supplied the required fields for the implemented bounded adapter.
- `partial` means the source showed useful reachability or inventory evidence but was not accepted for ingestion without a stricter production adapter/filter.
- `unusable` means the source was not accessible or parseable enough in this environment to support ingestion.
- Several public web/RSS/API candidates failed at TLS/network connection setup in this environment. Those failures are retained in `data/validation_report.json` and `data/source_feasibility.json`.
- Product records are now accepted only from the GitHub-hosted AI Tools List JSON directory sample when handle, website, description, and explicit AI description evidence are present. Provider/company remains `null` because the source does not reliably supply it.
- Hacker News Algolia, GDELT, Himalayas, and Models.dev were probed as alternative source candidates in addition to earlier blocked sources. They were not accepted because this environment returned TLS/SSL EOF before fields could be inspected.
- NPM search package results are accepted only as package/tool records after explicit AI relevance checks and package-specific registry verification; they are not treated as product records.
